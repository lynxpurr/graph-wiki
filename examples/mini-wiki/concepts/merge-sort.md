# Merge Sort

Merge sort is a stable divide-and-conquer [[sorting]] algorithm devised by
John von Neumann in 1945. It divides a sequence and merges sorted subsequences.

It runs in O(n log n) time and typically uses additional linear storage.
Its structure connects [[recursion]] with a fundamental design pattern in
[[algorithms]].
