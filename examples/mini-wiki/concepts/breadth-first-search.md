# Breadth-First Search

Breadth-first search traverses a [[graph-theory|graph]] by exploring each
vertex's neighbors level by level before moving deeper.

With adjacency lists it runs in O(V + E) time. It is used in [[algorithms]]
for reachability, unweighted shortest paths, and level-order traversal.
