# Linked List

A linked list is a linear collection of nodes connected by pointers. Each
node stores a value and a reference to another node, making it a fundamental
type of [[data-structures|data structure]].

Pointer updates allow efficient insertion and removal when a node is known,
while sequential lookup takes linear time. Many [[algorithms]] use linked
lists to maintain dynamically changing sequences.
