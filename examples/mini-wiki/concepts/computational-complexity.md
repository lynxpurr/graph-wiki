# Computational Complexity

Computational complexity theory classifies problems according to the resources
(time, space) required to solve them. [[big-o-notation]] provides an asymptotic
upper bound that can be applied to worst-case, average-case, or best-case
analysis.

The field builds on [[alan-turing]]'s foundational work on computability.
Practical [[algorithms]] analysis uses complexity to inform the choice of
[[data-structures]] and [[sorting]] strategies.
