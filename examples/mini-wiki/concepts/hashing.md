# Hashing

Hashing maps data of arbitrary size to fixed-size values using a hash function.
It enables efficient [[data-structures]] such as hash tables, which support
constant-time average lookups, given a well-distributed hash function and low
load factor.

Hash-based structures are widely used in [[algorithms]] for searching,
deduplication, and cryptographic verification. [[donald-knuth]] analyzed
hashing techniques extensively in TAOCP.
