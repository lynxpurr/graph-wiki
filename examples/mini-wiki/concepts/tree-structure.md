# Tree Structure

A tree is a hierarchical structure with a root and parent-child relationships.
It is an acyclic special case studied in [[graph-theory]].

Trees are fundamental [[data-structures]] for representing hierarchies and
supporting efficient search. Traversal and divide-and-conquer operations often
use [[recursion]].
