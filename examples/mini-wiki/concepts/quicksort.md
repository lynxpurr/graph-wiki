# Quicksort

Quicksort is a divide-and-conquer [[sorting]] algorithm developed by Tony
Hoare in 1960. It partitions elements around a pivot and sorts each partition.

Its average running time is O(n log n), though poor pivot choices can produce
O(n^2) behavior. It commonly uses [[recursion]] and is a foundational example
in the study of [[algorithms]].
